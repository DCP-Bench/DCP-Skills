# queens-enumeration

All solutions of n-queens, enumerated with blocking clauses (6-queens: 4, 8-queens: 92).

**Run:** `cargo run --release`
**Expected:** `6-queens: 4 solutions`
**Expected:** `8-queens: 92 solutions`

The helper functions at the top of `src/main.rs` are the same in every example of this skill.
